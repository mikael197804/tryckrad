# TryckRad

Analyserar Svenska Spels Powerplay (ishockey) **per speltillfälle**:

- Hämtar öppna omgångar från Svenska Spels API
- Bedömer odds + svenska folket
- Flaggar lag med tuff matchbelastning (matcher tätt inpå)
- Läser artiklar/nyheter kopplade till lagen
- Genererar systemrader i kupongformat för **48–720 kr**

```bash
npm install
npm run dev
```

Öppna [http://127.0.0.1:3000](http://127.0.0.1:3000).

Analysen är ett stöd – inga vinstgarantier. 18+.
