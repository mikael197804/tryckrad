# Mikael’s tips

Analyserar Svenska Spels Powerplay och Topptipset **per speltillfälle** – odds, tabelläge, vilomotiv, artiklar och system 48–720 kr.

## Live

- Webb: https://tryckrad.vercel.app (kräver inloggning)
- GitHub: https://github.com/mikael197804/tryckrad

Inloggning: namn + lösenord (egna konton). Admin (Mikael) kan skapa användare under **Användare**.

### Deploya gratis (Vercel)

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/mikael197804/tryckrad)

### Lokalt

```bash
npm install
npm run dev
```

18+. Spela ansvarsfullt.
